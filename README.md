# 🍽️ SmartBite Analytics

SmartBite Analytics is a smart canteen management system designed to streamline food ordering, inventory tracking, and data analysis. The system provides real-time insights to improve efficiency and decision-making.

---

## 🚀 Features

- 📋 Menu Management (Add, Update, Delete items)
- 🛒 Order Processing System
- 📦 Inventory Management with stock tracking
- 📊 Analytics Dashboard (Revenue, Orders, Insights)
- 📈 Data Visualization using charts
- ⚡ Fast and lightweight system using Streamlit

---

## 🛠️ Technologies Used

- Python
- Streamlit
- Pandas
- Plotly

---

## ▶️ How to Run

```bash
pip install streamlit pandas plotly
python -m streamlit run campus.py
